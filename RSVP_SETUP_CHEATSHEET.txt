STEP 1: DEPLOY GOOGLE APPS SCRIPT (3 minutes)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[ ] Go to: https://script.google.com
[ ] Click: "+ New Project"
[ ] Copy code from: GOOGLE_APPS_SCRIPT.js
[ ] Paste into editor
[ ] Click: Deploy → New Deployment
[ ] Type: Web app
[ ] Execute as: Your email
[ ] Who has access: Anyone
[ ] Click: Deploy
[ ] ⭐ SAVE this URL:
    https://script.google.com/macros/d/[...]/usercscript


STEP 2: CONFIGURE .env FILE (2 minutes)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[ ] Create file: .env (in project root)
[ ] Add line:
    VITE_GOOGLE_SCRIPT_URL=YOUR_URL_FROM_STEP_1
[ ] Save


STEP 3: TEST LOCALLY (2 minutes)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[ ] Run: npm run build
[ ] Run: npm run dev
[ ] Open: http://localhost:5173
[ ] Submit test RSVP
[ ] Check Google Sheet → data appears?
    ✓ YES → Success!
    ✗ NO → See TROUBLESHOOTING


STEP 4: DEPLOY TO VERCEL (3 minutes)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[ ] Go to: https://vercel.com
[ ] Select: izsabirthday2026
[ ] Settings → Environment Variables
[ ] Add: VITE_GOOGLE_SCRIPT_URL
[ ] Value: Your URL from Step 1
[ ] Redeploy
[ ] Test on production
[ ] Done! ✓
