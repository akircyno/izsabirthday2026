STEP 1: CREATE GOOGLE APPS SCRIPT WEBHOOK
─────────────────────────────────────────

  [1] Visit: https://script.google.com
  [2] Click: "+ New Project"
  [3] Copy code from: GOOGLE_APPS_SCRIPT.js (this repo)
  [4] Click: Deploy → New Deployment
      └─ Type: Web app
      └─ Execute as: Your Google Account
      └─ Who has access: Anyone
  [5] ⭐ COPY the Deployment URL
      Format: https://script.google.com/macros/d/[SCRIPT_ID]/usercscript


STEP 2: CONFIGURE THE WEBSITE
──────────────────────────────

  [1] Open: .env (in project root)
      If it doesn't exist, copy from .env.example
  
  [2] Add this line:
      VITE_GOOGLE_SCRIPT_URL=https://script.google.com/macros/d/[SCRIPT_ID]/usercscript
      
      ⚠️  Replace [SCRIPT_ID] with your actual Script ID from Step 1.5

  [3] Rebuild locally:
      $ npm run build

  [4] Test locally:
      $ npm run dev
      → Go to http://localhost:5173
      → Submit test RSVP
      → Check your Google Sheet


STEP 3: DEPLOY TO PRODUCTION (VERCEL)
──────────────────────────────────────

  [1] Go to: https://vercel.com
  [2] Select: izsabirthday2026 project
  [3] Settings → Environment Variables
  [4] Add new variable:
      Name: VITE_GOOGLE_SCRIPT_URL
      Value: Your full deployment URL from Step 1.5
  [5] Redeploy the project

TROUBLESHOOTING
───────────────

  Problem: No data in Google Sheet
  ├─ Check 1: .env has correct VITE_GOOGLE_SCRIPT_URL
  ├─ Check 2: Website rebuilt after .env change
  ├─ Check 3: Open DevTools (F12) → Console, submit RSVP, look for errors
  └─ Check 4: Google Sheet permissions (must be accessible)

  Problem: RSVP form still works but no Google Sheet sync
  ├─ This is OK! Data is saved locally in browser
  ├─ Check: Is VITE_GOOGLE_SCRIPT_URL environment variable set?
  └─ Solution: Set it in Vercel, redeploy, try again

  Problem: Permission error in Google Apps Script
  ├─ Solution: Run test function first
  ├─ Accept permission prompts
  └─ Try website RSVP again
